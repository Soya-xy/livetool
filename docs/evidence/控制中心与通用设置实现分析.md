### 4.2 保存机制

**自动保存**：几乎所有字段都挂了 watcher，改动后 **500 ms 防抖**自动提交；另有手动「保存」按钮。

```js
watch: {
  volume() { this.autoSave() },
  is_disable_gift_group() { this.autoSave() },
  isorder() { this.autoSave() },
  /* ... 每个字段一个 ... */
}

autoSave() {
  if (this.isFirstLoad) return;             // 首次加载回填时不触发
  clearTimeout(this.debounceTimer);
  this.debounceTimer = setTimeout(() => this.saveSettings(), 500);
}

saveSettings() {
  ipc.emit("onSubmit", ["set", 0, JSON.stringify({
    open_key, close_key, volume, webcast_url,
    auto_tab_pubg, is_disable_gift_group, isorder,
    is_disable_obs, is_gpu, is_inside_keyboard, is_outside_keyboard,
    debug_sleep, is_greenwindow, isproxy, isroomid,
    move_left_and_right_step, move_top_and_bottom_step,
    sph_isspeed, dy_isspeed, dy_conn_rule
  })]);
}
```

读取：`ipc.emit("getSet")` → 主程序回 `ipc.on("setData", json)` 回填。
平台：`ipc.emit("getUserPlatform")` → `ipc.on("userPlatform", ...)`。

### 5.1 界面

### 5.2 数据链路

     TielianAddCountMin / TielianAddCountMax /
     MosquitoHitMirrorX / MosquitoHitOffsetX / MosquitoHitOffsetY）
   ▼

### 5.3 行为语义

按界面文案与字段命名，语义明确：

> **收到「一组」多个礼物时，只执行 1 次动作，而不是按礼物个数执行多次。**

平台侧常见场景：观众一次连送 N 个同款礼物（抖音/快手会推成一条带数量的消息，也可能推成 N 条连续消息）。
- 关闭（默认）：N 个礼物 → 动作执行 N 次（或按礼物数量累加）。
- 开启：同一组礼物只触发 1 次，避免连击把画面刷爆。

**实现落点在 Go 的礼物事件处理里**（`myapp/core/danmu_handler.Gift` / `HandleEvent`）。
由于主程序被 Enigma 加壳，该分支的具体合并逻辑（按用户去重、按时间窗合并、还是按平台消息的 `count` 字段取一次）没有从二进制里直接读出，
但字段名 `is_disable_gift_group` 与文案「只执行1次操作」共同确定了行为契约。

**复刻建议**：

```go
func onGift(ev GiftEvent, cfg Config, rules []Rule) {
    if cfg.IsDisableGiftGroup {
        // 同一用户 + 同一礼物 + 短时间窗（建议 800ms~2s）内的多次礼物合并为一次
        key := ev.UserID + "|" + ev.GiftName
        if recent(key) { return }        // 直接丢弃后续，不执行动作
        mark(key)
    }
    dispatch(ev, rules)
}
```

### 5.4 与其它字段的关系

- **触发限制**（规则级 `trigger_gift_second`）：限制「同一用户多少秒内只触发一次」，粒度是**单条规则**、按用户。
- **禁用组刷**（全局 `is_disable_gift_group`）：限制「一组礼物只执行一次动作」，粒度是**全局**、按礼物组。

两者可以叠加：规则级限制更细，全局组刷更粗，用于兜底防止连击刷屏。

## 8. 复刻要点

1. **规则模型**就是 §2.1 的字段；`handlers` 是动作数组，每条动作是 §3.3 的对象。
2. **触发限制**与**禁用组刷**是两级节流，别合并成一个：前者按规则+用户，后者全局按礼物组。
3. **自动保存**用 500 ms 防抖；首次回填必须跳过，否则会覆盖用户配置。
4. **热键录入**只接受 `Digit/Numpad/KeyA-Z/F1-F12` + 修饰键，且最多 1 个。
5. **动作下拉**分「常用按钮」和「更多菜单」两层，命令名（keyboard/mouse/video/... /gospeed/tielian/mosquito/scaler）就是后台 handler 名。
6. **禁用OBS连接 / 硬件编码 / 内置键鼠 / 外置键鼠**都标注「重启生效」，复刻时要在启动时读取。
7. 表格行的 `置顶` 仅在第 2 行起显示（`$index >= 1`）。

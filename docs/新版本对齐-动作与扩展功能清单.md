### 2.4 内置事件表（`rule`）

事件 ID 与中文名对照来自原版前端 i18n，并在主程序 Go 侧 `0xF96E00–0xF97800`
的分派 switch 中逐个比对确认。完整逆向记录见
[docs/evidence/内置事件表-逆向记录.md](evidence/内置事件表-逆向记录.md)。

| 事件 ID | 中文名 | 持续时间 | 额外字段 |
|---|---|---|---|
| `kill_process_name` | 结束指定进程名 | 否 | `killProcessName` |
| `run_exe` | 运行一个应用程序 | 否 | `runExePath` |
| `shutdown` | 关机 | 否 | — |
| `restart` | 重启 | 否 | — |
| `sleep` | 睡眠 | 否 | — |
| `viewlock` | 锁屏 | 否 | — |
| `logoff` | 注销 | 否 | — |
| `minimized` | 最小化当前窗口 | 否 | — |
| `lock_awsd` | 锁定AWSD(罚站) | 是 | — |
| `lock_wsd` | 锁定WSD，自动按A(自动向左) | 是 | — |
| `lock_asd` | 锁定ASD，自动按W(自动向前) | 是 | — |
| `lock_awd` | 锁定WAD，自动按S(自动向后) | 是 | — |
| `lock_aws` | 锁定WAS，自动按D(自动向右) | 是 | — |
| `cf_quit_room` | 退出房间(穿越火线) | 否 | — |

`ruleEventTimeoutMs` 默认 1000，仅 5 个锁定事件使用，钳制在 1–600000。

**`effect` 取值**：`"增加"` / `"减少"`。
**`game` 取值**：`"tielian"` / `"mosquito"`。
**`sizeType` 取值**：`"mix"` / `"small"` / `"big"`。
**`speed` 范围**：1.0 – 2.0。
